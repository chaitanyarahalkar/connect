```ts
import { getToken } from '@connect/sdk';

// no secrets in env vars — a short-lived token, minted on demand
const { token } = await getToken({ connector: 'github', scopes: ['repo'] });
```

## Six primitives

<CardGrid>
  <Card title="Connector" icon="puzzle">
    Org-owned record for one provider: `api_key`, generic `oauth2` (PKCE), or `github`/`slack`
    presets.
  </Card>
  <Card title="Installation" icon="add-document">
    One tenant's grant (workspace, org, or individual user) — a connector serves many.
  </Card>
  <Card title="Token" icon="seti:lock">
    Short-lived credential minted per request; subjects: `app`, `user`, `jwt-bearer`.
  </Card>
  <Card title="Project link" icon="setting">
    Binds a connector to a project, per environment (production/preview/development).
  </Card>
  <Card title="Trigger" icon="rocket">
    Verified inbound webhook, forwarded to your destinations with a `connect-signature`.
  </Card>
  <Card title="Auth" icon="approve-check">
    Two legs: caller → Connect (OIDC workload JWT / PAT / session), Connect → provider (OAuth/API
    key).
  </Card>
</CardGrid>
